# ramneekkaur05-portfolio-website

Clean static portfolio site for Ramneek Kaur.

## Structure

- `index.html` - main portfolio page
- `404.html` - fallback page
- `assets/css/styles.css` - site styling
- `assets/js/main.js` - small navigation and UI behavior
- `assets/images/rk-pfp.jpg` - profile image
- `assets/resume/ramneek-kaur-resume.pdf` - resume

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Deployment

This repo is ready for static hosting on GitHub Pages, Netlify, or Vercel without a build step.
